### How I check my work

**The Lecture Machine**, inside Meds.krd. Several AI models, from different companies, turn a lecture into readable parts and practice questions. None of them checks its own writing, and anything that fails twice waits for a person.

**[Fine Print](https://github.com/arman-mahabad/fine-print)**. A Claude skill for long AI-built projects. Before the agent calls a feature done, it has to write down where the feature works, how that was seen, and what the check does not prove.

**[Kunji](https://github.com/arman-mahabad/kunji)**. A working prototype of an AI copilot that helps people write and check their replies. It never sends anything by itself, and it comes with a workspace for measuring how well it works.

**[Sorani skill](https://github.com/arman-mahabad/sorani-skill)**. Helps Claude write Sorani Kurdish with Kurdish letters instead of Arabic lookalikes, right to left. Its checker finds the common mistakes and fixes the safe ones.
